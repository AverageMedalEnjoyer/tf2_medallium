// WHAT TAGS DO:
[killer] (This can only be used in bot_deathmsgs.txt, or bot_deathmsgs_crit.txt. This is used to find the name of the player who killed the bot. Example; "Why'd you kill me, [killer]?"
[victim] (This can only be used in bot_killmsgs.txt. This is used to find the name of the player the bot has killed. Example; "Take that, [victim]!")
[teammate] (This can only be used in bot_praisemsgs.txt. This is used to find the name of the teammate the bot will praise. Example; "Nice job, [teammate]!")
[hatedplayer] (This can be only used in bot_insultmsgs.txt. This is used to find the name of a player the bot hates. Example; "I hate you, [hatedplayer]!")
[ourteam] (Can be used in every bot script. This is used to find the name of the bot's current tean.  Example; "We got this, [ourteam]!")
[enemyteam] (Can be used in every bot script. This is used to find the team opposite of the bot's current team. Example; "Suck it, [enemyteam]!")

[deathbyplayer] (This can only be used in bot_deathmsgs.txt, or bot_deathmsgs_crit.txt. This message is only used if the bot has died to a player.)
[deathbyself] (This can only be used in bot_deathmsgs.txt, or bot_deathmsgs_crit.txt. This message is only used if the bot has died to themselves.)
[deathbyrandomcrit] (This can only be used in bot_deathmsgs_crit.txt. This message is only used if the bot has died to random crits.)
[deathbybackstab] (This can only be used in bot_deathmsgs_crit.txt. This message is only used if the bot has died to a backstab.)
[deathbyheadshot] (This can only be used in bot_deathmsgs_crit.txt. This message is only used if the bot has died to a headshot.)

[80%_anger] (This can only be used in bot_insultmsgs.txt. This message is only used if the bot is at or above 80% current anger.)
[cocky] (This can only be used in bot_insultmsgs.txt. This message is only used if the bot is at or above 60% current cockiness and is below 60% current anger.)
